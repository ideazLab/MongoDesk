# Changelog

## [1.1.0]

- MongoDB workspace with multiple saved connections, database/collection tabs, and persistent workspace state.
- Table, tree, and JSON document views with reviewed document and nested-field mutations.
- Query execution, aggregation building, and saved pipelines.
- Database and collection import/export, including JSON, CSV, Excel, SQL, BSON archives, and collection copying.
- Background database backup scheduling and native application menus.
- Workspace branding and installers for macOS Apple Silicon, macOS Intel, Windows x64, and Linux x64.
- Unified app/installer version and a reviewed, signed-metadata draft-release process.
