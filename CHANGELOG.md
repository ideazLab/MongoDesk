# Changelog

## [Unreleased]

- In-app update checking, verified downloads, and installation will be integrated before the first update-enabled release is tagged.

## [1.1.0]

- Moved global toolbar actions into the platform menu bar and Settings.

- Platform-specific Settings and About menus with themed preferences and About/license-notices dialogs.

- Custom dark appearance with persistent Light, Dark, and live Follow system modes.

- Clear document pagination controls, result ranges, matching document counts, end-of-results indicators, and per-tab page sizes.

- Windows MSI creates Start menu and desktop shortcuts, with installation and uninstall registration verified in CI.

- MongoDB workspace with multiple saved connections, database/collection tabs, and persistent workspace state.
- Table, tree, and JSON document views with reviewed document and nested-field mutations.
- Query execution, aggregation building, and saved pipelines.
- Database and collection import/export, including JSON, CSV, Excel, SQL, BSON archives, and collection copying.
- Background database backup scheduling and native application menus.
- Workspace branding and installers for macOS Apple Silicon, macOS Intel, Windows x64, and Linux x64.
- Unified app/installer version and a reviewed, signed-metadata draft-release process.
